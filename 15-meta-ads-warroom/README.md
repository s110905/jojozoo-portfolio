# Meta 廣告戰情室：從素材矩陣到上線安全閘門

[⬅️ 返回作品集總覽](../README.md)

### 把檔期規劃、素材版本、受眾、追蹤與成效判讀集中管理，讓廣告不只上線，也能被驗證

> 成效驗證專案：4 周年慶以 1.6 萬小預算帶進 7,152 次有效到站（到達率 81.3%、每次到達 NT$2.35），現場問卷驗證 22.7% 遊客為廣告來源。

## 行銷卡點：檔期很多，但資料沒有在同一個地方說話

活動廣告牽涉文案、圖片、受眾、排程、預算、著陸頁與追蹤。只靠廣告後台逐頁查看，會出現三個問題：

* **版本容易失控**：不知道哪一則素材對應哪個受眾與優惠。
* **開檔風險晚發現**：著陸頁憑證或追蹤失效時，廣告費仍可能持續消耗。
* **成效口徑不一致**：平台點擊、GA4 事件與購票入口各自有數字，難以直接比較。

## 專案策略：把投放流程做成一套可檢查的系統

本專案不只建立廣告，而是把檔期前、中、後的工作串成同一套操作方式：

- **受眾與素材矩陣**：依親子、學生、情侶與暖受眾管理文案和素材版本。
- **檔期排程**：分開管理整月主訴求、限定日期優惠與再行銷節點。
- **UTM 與 GTM 規範**：統一活動來源、素材與購票入口的事件命名。
- **雲端戰情室**：集中查看廣告花費、點擊率與購票入口點擊。
- **上線安全閘門**：開檔前檢查 TLS 憑證鏈、著陸頁狀態、GTM 與 Meta Pixel。

## 已完成的實戰驗證（截至 2026/09/19）

* **規模化有效覆蓋**：累計曝光 **53.6 萬次**、觸及 **18.0 萬名**不重複用戶，平均頻率 2.65 次，健康未疲乏。
* **低成本高效導流**：以 **NT$16,811** 預算帶進 **7,152 次到達網頁（LPV）**，平均每次進站成本僅約 **NT$2.35**。
* **網站效能與到達率**：活動落地頁伺服器響應壓制在 **400ms 以內**，點擊後進站到達率高達 **81.3%**（遠超 60% 門檻）。
* **Node.js 自動化停投機制**：排程於自然客流飽和的週末假日自動暫停廣告，避開 Meta 週末高價競價，平日精準導流。
* **多源即時戰情室**：整合 Meta Marketing API、GA4 Data API、Open-Meteo 園區即時天氣／空品與 SSL 憑證鏈自動化檢驗。
* **實體入園成效驗證**：現場紙本問卷實測，有 **22.7% 入園遊客自陳由 FB／IG 廣告得知活動**，線上精準轉化為實體人流。

## 誠實揭露量測上限

購票由第三方平台完成，訂單資料不會回傳，因此目前只能判讀到「購票入口點擊」，不能直接宣稱 CPA 或 ROAS。專案以兩把尺補足實體閉環：

1. 透過現場紙本兌獎問卷，補上實體歸因鉤子（實測 22.7% 廣告自陳來源）。
2. 對照 GSC 自然搜尋趨勢（同期自然搜尋點擊成長 +43.5%）。

這個限制沒有被包裝成已完成成果，而是清楚留在檔期結案條件與架構備忘中。

## 系統架構

```text
受眾與素材矩陣
  │
  ├── Meta 廣告檔期與預算
  ├── UTM / GTM / Pixel 追蹤契約
  └── 上線前安全閘門
        ├── 著陸頁 HTTP 狀態
        ├── TLS 憑證鏈
        └── 事件是否正常送出
              │
              ▼
        雲端廣告戰情室
        花費 / CTR / 購票入口點擊
```
